# lab_5

**Погодный сервис** — это современный метео‑сервис, в котором бэкенд на Go и PostgreSQL автоматически собирает и обновляет погодные данные для городов всего мира по расписанию через cron. Сервис интегрируется с Open-Meteo Weather API и Geocoding API, чтобы получать актуальную температуру, условия и выполнять поиск городов с автодополнением по названию. Бэкенд использует gocron для фоновых задач, pgx и sql-migrate для работы с базой и миграций, а также in-memory кэш для ускорения ответов. Фронтенд на TypeScript и React с Material UI и React-Leaflet отображает погоду в виде адаптивных карточек, карусели популярных городов и интерактивной карты мира. Пользователь может найти город через строку поиска с подсказками, выбрать его щелчком на карте и сразу увидеть текущий прогноз. API предоставляет удобные эндпоинты для поиска города по текстовому запросу и получения погоды по названию города. Проект ориентирован на наглядный и удобный интерфейс, сочетающий красивый дизайн, карту и мощный Go-бэкенд для стабильной работы в продакшне.
